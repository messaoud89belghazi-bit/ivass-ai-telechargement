Installer en 1 minute

  1. Sur votre téléphone, touchez « Télécharger IVASS AI » ci-dessus.
  2. Ouvrez le fichier Ivass-AI-Mobile.apk téléchargé (notification ou dossier Téléchargements).
  3. Si Android le demande, autorisez « Installer des applications inconnues » pour votre navigateur, puis touchez Installer.
  4. Ouvrez IVASS AI, acceptez les conditions, puis ajoutez une clé d’IA. Une clé Google Gemini est gratuite : aistudio.google.com → « Create API key ».

Android peut afficher un avertissement car l’application ne vient pas du Play Store : c’est normal. Les mises à jour s’installent ensuite depuis l’application, sans perdre vos données.
