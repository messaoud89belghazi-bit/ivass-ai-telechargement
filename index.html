Installer en 1 minute

  1. Sur votre téléphone, touchez « Télécharger l’application » ci-dessus.
  2. Ouvrez le fichier Ivass-AI-Mobile.apk téléchargé (notification ou dossier Téléchargements).
  3. Si Android le demande, autorisez « Installer des applications inconnues » pour votre navigateur, puis touchez Installer.
  4. Ouvrez Ivass AI, acceptez les conditions, puis ajoutez une clé d’IA. Une clé Google Gemini est gratuite : aistudio.google.com → « Create API key ».

Android peut afficher un avertissement car l’application ne vient pas du Play Store : c’est normal. Les mises à jour s’installent par-dessus, sans perdre vos données.

Vos données

Vos clés API restent chiffrées sur votre téléphone. La synchronisation avec le PC est chiffrée de bout en bout : le serveur ne peut rien lire. Le programme d’amélioration est facultatif : rien n’est envoyé sans votre accord, tout est nettoyé et chiffré avant l’envoi, et vous pouvez tout faire effacer à tout moment.
