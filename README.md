## ✨ Ce que fait Ivass AI

- 🔗 **Rattacher** : GitHub, Notion, Hugging Face, Wikipédia, arXiv, Todoist, Trello, Airtable, dossiers du PC… et n’importe quel **serveur MCP**. Le **Radar de connaissances** détecte ce qu’Ivass connaît mal et l’apprend depuis GitHub et les sources ouvertes.
- 📦 **De vrais fichiers, pas du code** : CV, facture, rapport, budget, présentation… Ivass crée directement le fichier **Word, PDF, Excel, PowerPoint ou CSV**, ainsi que vos **images** et **vidéos**, prêts à ouvrir et à partager.
- 🤖 **Toutes les IA réunies** : Claude, Gemini, ChatGPT, Groq, Mistral… Si une IA est en panne, la suivante reprend la réponse.
- 🧠 **Réflexion profonde** : brouillon, relecture experte, puis réponse corrigée.
- 📚 **Mémoire intelligente** : vos notes et méthodes deviennent la mémoire de l’IA, même sans réseau.
- 🔄 **Synchronisation PC ↔ téléphone**, chiffrée de bout en bout.
- 🎨 **À votre image** : thèmes clairs ou sombres, arrière-plans, taille du texte.

## 🛠 Installation

- **PC** : ouvrez le fichier `.exe`. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur *Informations complémentaires*, puis *Exécuter quand même* (logiciel récent, pas encore connu de Microsoft).
- **Android** : ouvrez le fichier `.apk` ; si Android le demande, autorisez « Installer des applications inconnues ».
- Au premier lancement, ajoutez une clé d’IA : une clé **Google Gemini** est gratuite sur [aistudio.google.com](https://aistudio.google.com/app/apikey).
